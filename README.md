## 2026-11: Open-Meteo HTTP 429 및 KMA 비·눈 예상지역 누락 감사

- 기상청 단기 256개는 계속 독립 수집합니다. ECMWF는 **167개 시·군·109개 구를 각각 IFS/AIFS로 조회**하되, 기상청이 비·눈을 예보한 날짜별 지역을 **먼저** 각 모델에서 조회합니다. 이후 모든 지역이 가능하면 조회되며 성공을 보장한다고 주장하지 않습니다.
- Open-Meteo `HTTP 429` 요청 제한을 받으면 동일 실행에서 모델/구마다 다시 반복 요청하지 않고 중단하며, 시·군·구별 수집 실패 사유를 기록합니다. 다음 자동실행은 최소 30분 유예 또는 제공사 지시한 `Retry-After`를 고려합니다. Open-Meteo 무료 API 이용 조건을 존중합니다.
- 단 **일부 최신 수집에 성공했어도 과거 전체 성공본을 즉시 폐기하지 않습니다**. 같은 167+109 범위의 모델별 지역마다 원래 수집 시각을 남기고 **3시간을 초과한 구 자료는 재사용하지 않습니다**. 보존한 최신 성공본을 새 수집 성공과 혼동하지 않도록 구분합니다.

## 2026-11: 날짜별 시·구·군 통합 PDF / 표

- 기존 KMA 원본 수집 대상 **256개(구 109·시 65·군 82)**는 바꾸지 않습니다. PDF에서는 날짜별로 비·눈 예보가 있는 시·구·군 모두를 **한 표**에 표시하고, 같은 지역 행에 총강수량(PCP, mm)과 신적설(SNO, cm)을 나란히 둡니다.
- 비와 눈을 두 개의 서로 다른 표로 반복하지 않습니다. **신적설 범위 상한이 0cm보다 큰 지역을 먼저 적설량 많은 순**으로, 그다음 **적설량이 0 또는 미제공인 지역을 총강수량 많은 순**으로 정렬합니다. 적설량이 같으면 강수량이 많은 순입니다. 미정량은 뒤에, 상한이 없는 범위는 알려진 하한으로 정렬하며, 기간이나 구간이 달라 절대적인 순위라고 주장하지 않습니다.
- **ECMWF IFS·AIFS**도 기존 **167개 시·군**과 별도 **109개 구**의 실제 조회 성공 자료를 날짜별 **시·구·군 한 표**로 결합합니다. 각 지역 한 행에 IFS 총강수·신적설과 AIFS 총강수·신적설을 모두 표시합니다. 정렬에는 IFS/AIFS 중 큰 유효 신적설량을 우선 사용하고, 적설량이 0 또는 미제공인 경우 두 모델 중 큰 실제 총강수량을 참고용으로 사용합니다. 실제 값은 모델별로 계속 구분합니다.
- 같은 지역에서 한 모델은 **실제 0mm**, 다른 모델은 **양의 강수량**인 경우에도 0을 유지하고, 조회 실패·미제공은 0으로 가정하지 않고 '미제공'으로 표시합니다.
- PDF 표에는 실제 비·눈 예보가 있는 지역만 표시하지만, 수집 원본은 무강수 지역도 보관합니다. 총강수량은 눈을 포함한 물의 양(mm)이며 신적설(cm)과 합산하거나 동일 단위로 비교하지 않습니다.
- 기존 PDF 파일 경로와 매니페스트의 호환용 `scope=city_only`, `coverage_scope=city_district_county`, 4회 알림·Cloudflare 스케줄은 그대로 둡니다. 통합 표 전용 `pdf_layout_version=unified_kma_ecmwf_v1`와 행 건수를 추가 기록합니다.

## ECMWF 기존 시·군 + 구별 독립 참고 예보

- 기상청 수집은 이미 공식 구 109개, 시 65개, 군 82개 = **256개 구·시·군**을 유지합니다.
- ECMWF는 기존 **167개 시·군 참고 지점**을 모델별로 우선 요청한 뒤, **109개 구별 참고 지점**을 *별도* 요청합니다. 두 층을 합치면 **276개 지역 라벨**이며, 서로 다른 ECMWF 실제 모델 격자 수가 276개라는 뜻은 아닙니다.
- 새 구별 ECMWF 요청의 실패·시간초과는 기존 시·군 결과나 기상청 단기예보 게시를 막지 않습니다. 167개 시·군의 성공 건수와 109개 구의 성공 건수를 따로 표시하고, 조회하지 못한 구를 성공으로 계산하지 않습니다.
- PDF는 기존 시·군 요약과 **기상청 구별 상세**, 실제 확보된 경우에만 **ECMWF 구별 참고 표**를 추가합니다. 무강수 구는 비·눈 상세 표에서 제외됩니다.
- 두 모델에서 시·군별 참고 좌표는 여러 기상청 구 대표 격자의 근사 평균이며, 구별 참고 좌표는 해당 공식 구 격자를 위경도로 역변환합니다. 모두 행정구역 전체 평균·기상청 구 예보와 동일한 ECMWF 값이 아닙니다.
- 기존 PDF 알림의 `scope=city_only`는 호환성 때문에 유지하며, `coverage_scope=city_district_county`로 새 상세 범위를 표시합니다.
- 기존 자동 알림 4회 및 Cloudflare 백업 스케줄은 수정하지 않습니다.

## 이전 ECMWF 167개 시·군 기준 설명

- 공식 기상청 2단계 대표 격자표에서 시/광역시 단위 85개, 군 82개를 합쳐 167개 참고 지점을 조회합니다. 구는 해당 시로 통합합니다.
- IFS/AIFS는 해당 행정구역의 공식 평균값이 아니라 KMA 대표 격자를 역변환한 근사 위경도에서 계산된 모델 참고값입니다.
- 모델별 10개 이하의 좌표를 묶음 요청하여 성공한 일부 지역 데이터는 유지하고 장애 시에는 빈 모델 페이지를 제외합니다.
- 군 수집 중 일부 지역에 네트워크 장애가 생겨도 기존 구·시 174개가 전부 정상이라면 게시를 유지하고 PDF에 실제 성공 수를 표시합니다.
- 기존 ChatGPT/Cloudflare 갱신 검증과 호환되도록 PDF 매니페스트의 `scope=city_only`는 변경하지 않고 새 `coverage_scope=city_and_county`를 추가했습니다.
